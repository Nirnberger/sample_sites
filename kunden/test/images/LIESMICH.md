# Eigene Fotos für test

Fotos gehören nicht ins Git-Repository, sondern in den Objektspeicher:
`node scripts/medien.js hochladen test` (Zugangsdaten siehe HOSTING.md). Beim Build landen sie hier.

Ein Foto ersetzt das gleichnamige Bild der Vorlage (z. B. `hero.jpg` für das große Foto oben).
Erlaubt: JPG, PNG, WebP. Fehlende Fotos werden aus der Vorlage übernommen.
